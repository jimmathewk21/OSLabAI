OSLabAI

An AI-Powered Assistant for Operating Systems Laboratory Learning

The application retrieves relevant passages from a curated OS knowledge base and generates answers using a local language model.

Current implementation
▤

Knowledge base

Seven topic groups covering scheduling, deadlocks, memory, synchronization, file systems, OS basics, and CPU/process concepts.

⌁

Preprocessing and retrieval

Text embeddings and cosine similarity identify passages relevant to a student's question.

⌘

Answer generation

A local language model generates explanations using retrieved knowledge-base passages.

◷

Local web application

A Flask web interface connects the browser to the Python retrieval and answer-generation pipeline.

SYSTEM DESIGN

Implementation

How a question moves through the application.

01
User question

The question is entered in the website chat.

02
Question embedding

Ollama converts the question into a numerical vector.

03
Semantic retrieval

Cosine similarity ranks knowledge-base passages.

04
Relevance filtering

Questions with weak matches are rejected.

05
Answer generation

The local language model answers using retrieved context.
