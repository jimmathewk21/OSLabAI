OSLabAI

An AI-Powered Assistant for Operating Systems Laboratory Learning

The current prototype answers OS questions by matching normalized question words against a curated dataset and topic keywords.

Current implementation
▤

Knowledge base

Seven topic groups with explanations for scheduling, deadlocks, memory, synchronization, file systems, OS basics, and CPU/process concepts.

⌁

Preprocessing

Lowercase conversion, regular-expression tokenization, stop-word filtering, and synonym normalization.

⌘

Answer selection

Topic scores combine content-word matches and weighted keyword matches. Relevant sentences are then selected.

◷

Local web application

A Flask web interface connects the browser to the existing Python question-answering logic.

Results and discussion

The current prototype successfully handled the reported OS and process/thread test cases. Earlier issues included short queries, ambiguous topic scores, and misplaced dataset content. The current approach is simple and fast, but keyword overlap can fail when users phrase a question in an unfamiliar way. A larger labelled test set is needed before reporting an accuracy percentage.

Future work

Explore similarity-based retrieval

Potential alternative: preprocess the question, calculate TF-IDF vectors, rank stored sentences with cosine similarity, apply a confidence threshold, and return the best-supported answer. Semantic search or an external language model could be evaluated later. These changes require implementation and testing before they can be claimed as completed.
